## 飛行遊戲（fling.js）

- **等級**：一週一級、沒有上限；每一級多一次噴射。噴射後多彈地兩次。
- **朋友**：九種（兔、蛙、蘑菇／萬聖節魔女缸、熊、貓頭鷹、長頸鹿、山豬、刺蝟、松鼠），不會連續兩個一樣。
  - 長頸鹿的碰撞是整張圖的輪廓（每欄量上下緣），往上彈碰到脖子也算；其他朋友只算往下落時。
- **super bounce**：星星條滿了踩朋友（蘑菇／魔女缸不算）。
  - 朋友特寫 cut-in 1.5 秒，配環狀倒數。
  - 「TAP!」在有效窗口前 0.1 秒出現。有效窗口是爆發前 0.3 秒到爆發後 0.1 秒，點中再加強 50%，配清亮獎勵音；太早按就圈散掉，並顯示「太早了」。
  - bunny bounce 本身就會發動 super bounce；同時星星滿了就疊加（「BUNNY + SUPER!」）。俯衝加成再乘上去。兔子不會停在兔子或蘑菇旁邊。
- **破紀錄**：越過「最遠」紅旗的瞬間整個畫面慢動作，接著出「破紀錄！」橫幅。在雲上破紀錄時，等下來碰到第一隻朋友飛出去之後才播。
- **雲端路段**：150 m 才上去。寬三條道，左右超出就踩空摔下（4 格摔落動畫，左右鏡像）。
  - 吃星星集星星條，滿了終點必出金卡。
  - 終點煞車（拖出煙霧）、坐下左右看卡，5 秒內點一張就往那張方向跳，沒點就自動選等級最高的。
  - 下來時底下放熊和刺蝟以外的隨機朋友。
- **卡片**：所有卡都有 GPT 畫的圖（`assets/cards/`、萬聖節版 `assets/cards/halloween/`），三個等級共用一張；「更常出現」是 +20/30/40%。
- **滑翔**：彩虹滑翔傘（三格被風吹的動畫，往斜後方張開）。白天也有著地滑行圖。
- **萬聖節**：小狐披風版（雲端終點三段也有）、朋友服裝版卡片和 cut-in。
- **其他**：靜音鈕（全 app 共用，記在瀏覽器）。電腦上視窗是直的也會用橫向畫面顯示。

### 對戰（一起飛）

- 家長版「孩子們」可以管理多個孩子，每個孩子旁有「🦊 一起飛」。之後上游又加了雙向挑戰、推播通知、家長 PIN、App 內掃 QR。
- 用 Supabase Realtime 廣播（`Link.room`，不存資料、不改資料庫）：
  - 邀請在房間 `family-配對碼`，對戰在房間 `battle-房號`。
  - 一起倒數，看得到對方半透明的小狐；兩邊都落地才公布輸贏。
  - 兩邊都用孩子的等級，對戰時沒有開局選卡。
- **合體技**：兩隻在空中相撞，播合體 cut-in；兩邊都點中 perfect，就用貓頭鷹的方式（25°、帶滑翔）飛出，力道 ×1.5。每局一次。
- 上游另外加了**救援卡**：雲端終點中間那張，藍／紫／金。

## 飼養區（app.js / fox2d.js / ball.js）

- **位移規則**：只有標記 `walk`（走路循環）或 `jump`（撲擊起跳）的片段可以移動小狐（`Fox2D.state.moves`），只套用在飼養區。
- **食盆**：GPT 畫的（肉、菜、水各滿／半／一點，加空碗）。
  - 放在離小狐有段距離的地上，小狐走過去吃。
  - 分兩層：低頭吃的那段，碗的後半圈在小狐臉下面；其他時候整個碗在前面。
  - 前半圈圖由 `tools/bowl_layers.py` 切出（`*_front.png`）。
- **追球**：拿球時蹲姿，頭會跟著球轉（`ready_loop_look_l/_r`，從 11/01 拿掉前的版本還原）。
- **其他**：床已移除，小狐在原地睡。音樂由預載頁的點擊開始播。

**測試參數（fling.html）**：

| 參數 | 用途 |
|---|---|
| `?ready` | 一開始星星條就滿 |
| `?friend=bear` | 只出指定朋友 |
| `?sky` | 直接上雲端 |
| `?auto` | 雲端自動走 |
| `?hold` | `?auto` 時不自動選卡 |
| `?soar` | 從起飛就滑翔 |
| `?level=n` | 指定等級 |
| `?nocards` | 不抽開局卡 |
| `?bg=day` / `?bg=halloween` | 指定白天／萬聖節 |
| `?debug` | `window.__fling()`、`window.__battle()` 讀遊戲狀態 |
