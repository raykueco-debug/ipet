# 親子連動（Supabase）

父母端（`parent.html`）送食物給孩子的小狐（`index.html`），經由 Supabase 傳遞；GitHub Pages 沒有伺服器，所以不能用 server.py 的 `/api`。

- 專案：Supabase「ipet」（raykueco-debug's Org，2026-11-02 建立，機房 West EU / Ireland）
- 網址與金鑰：`link.js`（publishable key，本來就是給網頁用的；能做的事只有 SQL 裡授權的兩個函式）
- 資料庫設定：`docs/supabase.sql`（已在 SQL Editor 執行過；改了再貼一次、按 Run 即可，可重複執行）

## 怎麼運作

1. 孩子的小狐第一次打開時，自動產生一組 10 碼的配對碼（不含 0/O、1/I），在小狐的「設定」裡看得到，旁邊有 QR 碼和「把家長版連結傳給爸媽」。
2. 爸媽用手機相機掃那個 QR 碼（或點傳來的連結）→ 打開 `parent.html?family=配對碼`，自動配對並記住；也可以在上方「配對碼」手動輸入。
   哪邊是孩子、哪邊是家長，看打開的是哪個網址：`index.html` 是孩子的小狐，`parent.html` 是家長版（蛋孵化前的畫面有「我是家長」連到家長版）。
3. 爸媽按「肉肉／蔬菜／一碗水」→ `send_gift(配對碼, meat|veg|water, 爸媽)` 存一筆。
4. 孩子的小狐每 4 秒呼叫一次 `pet_inbox(配對碼, 上次看到的 id)`，有新的就說「爸媽送來 🍖，放進儲物箱了！」，存進小狐的儲物箱（左欄 📦，存在孩子手機上）。第一次只記下目前最新的一筆，不會重播以前送的。
5. 什麼時候吃由孩子決定：點 📦 → 選一樣按「餵牠」，小狐才端碗出來吃（水就喝水），吃了才從箱子扣掉；吃太飽時不吃，留在箱子裡。

## 安全

- 表格 `pet_events` 開了 RLS、沒有任何 policy：直接讀寫一律拒絕。只能透過 `send_gift`、`pet_inbox` 兩個函式，而且一定要知道配對碼。
- `item` 只接受 meat / veg / water，其他會被資料庫拒絕。
- 這是原型：沒有登入，配對碼就是唯一的鑰匙。正式版要改成父母帳號登入、配對碼換成一次性的 QR 配對，並加上送禮次數限制。

## 還沒接上 Supabase 的

- 父母端的「讓小狐說話」（固定台詞、打字、錄音）仍走 server.py，只在區網內的本機伺服器能用。
- 金幣、看廣告、購買都還是示意。

## 綁定、挑戰（一起飛）與多個孩子

- **綁定一次就好**：爸媽掃孩子小狐的 QR 碼（`parent.html?family=配對碼`）就綁定了，兩邊都記住（家長：`ipet-parent-kids`；孩子：`ipet-parents`）。家長版開著時每 4 秒在房間 `family-配對碼` 喊一次 `parent-hi { pid, name }`，小狐回 `kid-hi`，家長版的孩子旁邊就顯示「在線上」。
- **解除／重綁**：家長按孩子旁的 ✕ → 送 `unpair { pid }`，小狐把這位家長移掉；孩子在 ⚙︎ 設定按「解除綁定」→ 送 `unpair { code, kid }`，家長那邊自動移除，小狐換一組新的配對碼，重新掃 QR 碼就能再綁。
- **互相挑戰**：家長按孩子旁的「🦊 挑戰」，或孩子按左欄「🦊 挑戰爸媽一起飛」→ 每 1.5 秒送 `challenge { room, from }`（最多一分鐘）；對方跳出確認，按「接受」送 `accept`、按「等一下」送 `decline`。接受後雙方進同一個房間 `battle-房號`（`fling.html?battle=房號&host=1` 是家長那邊，當主持）。孩子的挑戰若有兩位家長，先接受的那位拿到（小狐回 `start { pid }`）。
- 對戰本身：兩邊都進來後 3、2、1 一起倒數，飛的時候互傳位置，對方的小狐半透明、頭上有名字；兩邊都落地才公布誰飛得遠，「再比一次」要兩邊都按。都用孩子的等級（噴射次數），沒有開局選卡。
- 都是 Realtime 廣播，不存資料、不用改資料庫；挑戰只送得到**開著的**那一邊（網頁沒有推播）。

## 推播（挑戰時對方的手機／平板跳通知）

- 開通知：孩子在 ⚙︎ 設定（綁定後）按「🔔 開啟通知」；家長在「孩子們」下面按「🔔 開啟通知」。iPhone／iPad 要 iOS 16.4 以上，**而且要先加入主畫面、從主畫面打開**才能開（家長版有自己的 `parent.webmanifest`，加到主畫面就是「小狐家長版」App）。Android／電腦的 Chrome 直接允許即可。
- 存哪裡：表 `push_subs`（配對碼、kid／parent、推播地址），只能透過 `save_push`／`drop_push`；解除綁定時自動刪掉那個配對碼的訂閱。
- 誰送：Edge Function `notify`（原始碼 `supabase/functions/notify/index.ts`，在後台 Edge Functions → notify → Code 貼上、Deploy updates）。GET 回推播公鑰；POST `{ family, to, title, body, url, tag }` 送給對方所有裝置。同一配對碼＋角色 10 秒內只送一次；失效的訂閱（404／410）自動刪除。
- 金鑰（VAPID）：函式第一次被呼叫時自己產生，存在表 `push_keys`，沒有人經手私鑰；要換金鑰就清空那張表（之後大家要重新按一次開啟通知）。
- 挑戰等待時間拉長成 3 分鐘，讓對方有時間從通知點進來；點通知會打開（或切回）小狐／家長版，挑戰的確認框自己跳出來。

## 在 App 裡掃 QR 碼、家長密碼

- iPhone／iPad 上「加入主畫面」的 App 有自己的資料，用內建相機掃 QR 碼會跳到 Safari、綁在 Safari 那邊。所以要在 App 裡掃：
  - 爸媽的裝置用小狐 App：⚙︎ 設定 →「📷 我是家長：掃孩子的 QR 碼」→ 輸入家長密碼 → 掃孩子小狐設定裡的 QR 碼 → 進家長版、綁好。
  - 爸媽的裝置用「小狐家長版」App：孩子們下面「📷 掃孩子的 QR 碼來綁定」。
- 家長密碼（4 位數）：第一次進家長版時設定（輸入兩次），存在這台裝置（加鹽雜湊，`ipet-parent-pin`）；每次打開 App 進家長版要再輸入一次。忘記：答一題乘法就能重設。
- 掃描用 jsQR 1.4.0（`jsqr.js`，Apache-2.0），第一次掃描才載入。
