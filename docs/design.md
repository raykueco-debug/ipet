# 小狐：親子連線電子寵物設計

## 1. 兩個 App

| | 兒童端「小狐」 | 家長端「小狐 家長版」 |
|---|---|---|
| App Store 類別 | 兒童（Kids） | 一般（生活／娛樂） |
| 購買、廣告 | 完全沒有 | 金幣：Apple 內購（消耗型）、看廣告兌換（獎勵型） |
| 麥克風 | 不要求 | 只在錄音變聲時要求 |
| 主要功能 | 養寵物、收禮物、聽寵物說話 | 送零食與周邊、排程寵物說話、看寵物狀態 |
| 帳號 | 不需要帳號，只存配對 ID | 家長帳號（Sign in with Apple） |

配對方式：家長版產生配對碼或 QR code，兒童端掃描後綁定同一個家庭。

## 2. 後端

- 家庭資料：配對、寵物狀態摘要、排程、禮物與訊息收件匣、金幣帳本。
- 金幣只在伺服器加減：先驗證內購收據（App Store Server API）和廣告獎勵（伺服器端回呼），通過後才入帳。
- 兒童端取資料的方式：開著 App 時即時同步；沒開時，到了排程時間由推播通知「小狐有話要跟你說」，點開後再播放。
- 原型用 `server.py` 代替後端，正式版可以用 Firebase、Supabase 或 CloudKit。

## 3. 寵物說話（排程）

- 家長選擇內容（a、b、c 三種），再選「立刻說」或「指定時間」，可以設定「每天重複」。
- 排程存在伺服器，時間到了放進兒童端的收件匣。
- 寵物播放時會跳出對話泡泡、播放聲音，嘴巴會一開一合。
- iOS 規定聲音必須由使用者觸發：如果孩子還沒碰過螢幕，寵物會先說「有人傳話給你！點我聽聽看」，孩子點一下才開始播放。
- 建議加的規則：安靜時段（例如 21:30–07:00 不發聲，或改成只顯示文字）、每天的則數上限、每則字數上限（目前是 40 字）。

## 4. 語音方案評估

| | a. 內建固定台詞 | b. 打字自動發音（TTS） | c. 錄音變聲 |
|---|---|---|---|
| 家長操作 | 點選台詞 | 打字 | 按住錄音 |
| 聲音品質 | 最好，可以請配音員錄製，聲音一致 | 普通到好，取決於語音引擎 | 好，但效果取決於變聲演算法 |
| 情感 | 中，台詞固定 | 低到中 | 最高，聽得到家長的語氣 |
| 內容安全 | 最安全，台詞都事先審過 | 家長自己打的字，風險低，可加字數和關鍵字過濾 | 錄音內容無法審核，但只來自家長 |
| 兒童端隱私 | 無資料 | 只有文字 | 會收到家長的錄音檔 |
| 離線 | 可以，音檔內建在 App | 裝置內建語音引擎可以離線 | 需要先下載錄音檔 |
| 成本 | 一次性配音費 | iOS 內建引擎免費；雲端 TTS 依字數收費 | 幾乎免費，只有儲存和流量 |
| 開發量 | 低 | 低（內建引擎）或中（雲端引擎） | 中 |
| 推薦階段 | 第一版 | 第一版 | 第二版 |

### a. 內建固定台詞
- 正式版每句台詞內建一個音檔，由配音員錄製，或用 TTS 預先生成後人工挑選。原型暫時用 TTS 代替。
- 台詞按情境分類：問候、提醒（吃飯、刷牙、寫功課、睡覺）、鼓勵、愛。原型目前內建 16 句。
- 優點：品質最穩，最適合排程類的「生活提醒」。
- 缺點：無法客製化，需要定期新增台詞，可以當作新內容推出。

### b. 打字自動發音
- 最簡單的做法：兒童端用 iOS 內建的語音合成（AVSpeechSynthesizer），把音高調高，聽起來像小狐狸。免費、可離線、不經過第三方伺服器。
- 進階做法：家長送出時，由伺服器用雲端 TTS 生成專屬的小狐聲音（可以自訂音色），再傳給兒童端。聲音更像角色，但每字都要付費，也要處理文字傳到第三方的隱私問題。
- 風險：內建語音的童趣感有限，聽起來偏機器音。中文的破音字可能唸錯，例如「長大」和「長短」的「長」。
- 建議：第一版用內建語音，收集回饋後再決定要不要升級雲端語音。
- 原型已接好雲端神經語音：`server.py` 偵測到 Azure 或 OpenAI 的金鑰就自動改用，生成的音檔快取在 `data/tts/`，同一句只生成一次；沒有金鑰時退回裝置語音。裝置語音的音高從 1.7 降到 1.25，太高的音高正是聽起來生硬的主因之一。

### c. 錄音變聲
- 家長版錄音最多 10 秒，套用變聲後上傳，兒童端播放。
- 原型用提高播放速度的方式變聲，聲音會變尖、語速也會變快，像花栗鼠。正式版要用能保持語速、只改音高和音色的處理，例如 iOS 的 AVAudioUnitTimePitch 加上等化器，效果才會像角色在說話。
- 優點：情感價值最高，孩子會覺得「小狐在幫爸媽傳話」。
- 注意：
  - 孩子可能聽得出是家長的聲音，看你要把它當成驚喜還是破梗。
  - 錄音檔屬於家長的個資，要設保存期限（例如播放後 7 天刪除），並寫進隱私權政策。
  - 兒童端不需要麥克風權限，對上架兒童類別有利。

### 建議
第一版做 a 加 b（用內建語音），涵蓋提醒和自由留言，成本最低。第二版再加 c，當作家長版的亮點功能。

## 5. 原型範圍（網頁版）

- `index.html`：兒童端。每 4 秒檢查一次收件匣，收到後播放訊息和禮物。
- `parent.html`：家長端。送零食、三種說話方式、排程清單。金幣、廣告、購買只是畫面示意。
- `server.py`：原型後端，用檔案存資料，放在 `data/`。
- 限制：iPhone 用區網 http 連線時不能錄音（瀏覽器要求 https），c 方案請在電腦的 localhost 上測試。

## 6. 中英雙語與英文學習

**語言**
- 介面可切換中文或英文：兒童端在「設定」切換，家長端在頁面最下方切換。
- 小狐說話的語言由內容決定：句子裡有中文字就用中文聲音，否則用英文。固定台詞是中英雙語，家長可以選「小狐說：English／中文」。
- Azure 的預設聲音：英文 `en-US-AnaNeural`（童聲），中文 `zh-TW-HsiaoYuNeural`。可以用環境變數 `AZURE_TTS_VOICE_EN`、`AZURE_TTS_VOICE_ZH` 更換。

**學英文（兒童端「Learn／學英文」按鈕）**
1. **每日單字**：每天一個新單字，小狐會唸單字和例句；中文介面另外顯示中文意思。按「我學會了」會加小狐的快樂值和親密度。
2. **聽音選圖**：每輪 5 題。小狐唸一個字，孩子從 4 張圖中選，答對小狐會開心，最後依答對題數給星星。
3. **跟讀練習**：孩子對著麥克風唸，用語音辨識比對，給 1–3 顆星；唸對了也算學會。
- 單字表目前有 40 個字，放在 `words.js`，原型先用 emoji 當圖片。

**跟讀練習的隱私（上架前必看）**
- 兒童端需要麥克風權限，而孩子的聲音屬於兒童個資。原型用的是瀏覽器內建的語音辨識，Chrome 和 Safari 都會把聲音送到雲端處理。
- 正式版建議用 iOS 的 `SFSpeechRecognizer`，並設定 `requiresOnDeviceRecognition = true`，讓辨識完全在手機上完成、錄音不離開裝置。
- 如果要做更精準的發音評分，例如 Azure Pronunciation Assessment，就要把孩子的錄音上傳到雲端。這需要取得家長同意，也要符合美國 COPPA 等兒童隱私法規。建議第一版只做裝置端辨識。
- 家長版應該提供「關閉跟讀（麥克風）」的開關。

## 7. 語音改用內建離線模型（Kokoro）

裝置語音和雲端語音都被評為太生硬，改用開源的 Kokoro 模型（Apache 2.0 授權，可以商用），透過 sherpa-onnx 執行。

- **原型**：`server.py` 預設使用本地模型，程式在 `localtts.py`，模型放在 `models/`。
  - 第一次生成一句約 2–4 秒，之後從快取讀取。
  - 伺服器啟動時會先把 16 句固定台詞的中英版本都生成好。
- **選聲音**：開 `/voices.html` 試聽候選聲音、調整語速，按「用這個聲音」後整個 App 都會換成它。選擇存在 `data/voice.json`。
- **兩個模型**：
  - v1.0（約 132 MB）：約 50 個英文聲音（af_heart、af_bella、af_nicole…），另有 4 個中文聲音。
  - v1.1（約 147 MB）：中文為主，有 55 個女聲和 45 個男聲，英文聲音只有 3 個。
- **正式 App**：sherpa-onnx 有 iOS 版本，同一個模型可以直接放進 App，在手機上生成語音。不用網路、沒有雲端費用，孩子的資料也不會離開手機。
  - 代價是 App 會變大約 130–150 MB。英文為主的話，建議只放 v1.0（中文用它內建的 4 個中文聲音），或第一次開啟時再下載模型。
- **雲端語音（Azure、OpenAI）的程式碼保留**：設定 `TTS_PROVIDER=azure` 就可以切回雲端。

### 7.1 童趣變聲
Kokoro 的聲音都是成人嗓音，所以在生成後再加一道 Praat 的「Change gender」處理，用 `parselmouth` 執行，一句只要約 0.02 秒：
- **音高**：新的平均音高，單位 Hz。越高聽起來越小。
- **體型**（共振峰偏移）：把聲道「縮小」，聽起來像小動物，而不是大人捏著嗓子。只調音高會像花栗鼠，童趣感主要靠這一項。
- **活潑度**：放大語調起伏，聽起來更俏皮。中文有聲調，調太大會唱歌化，所以中文預設比英文保守。

試聽頁有四個預設：原聲、小孩、小狐狸、卡通，也可以用滑桿細調。這三個值和聲音一起存在 `data/voice.json`。
正式 App 的「打字發音」可以放在後端執行：自架的 Kokoro 加上變聲，只花自己伺服器的運算資源，不會有按字計費。固定台詞則上架前先生成好，放進 App。
